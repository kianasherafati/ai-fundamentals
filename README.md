# AI Fundamentals

Four projects from my **Fundamentals and Applications of Artificial Intelligence** course at Amirkabir University of Technology (Tehran Polytechnic).

The collection covers state-space search, constraint satisfaction, adversarial search, reinforcement learning, and probabilistic inference. Each project includes its implementation and original course report.

| Project | Main ideas | Explore |
| --- | --- | --- |
| Sokoban search | DFS, BFS, uniform-cost, greedy, and A* search; Pygame interface | [Project](01-search-sokoban/) · [Report](01-search-sokoban/report.pdf) |
| Constraints & game search | Crossword CSP with AC-3 and backtracking; Isolation with minimax, alpha-beta pruning, and expectimax | [Project](02-constraints-and-adversarial-search/) · [Report](02-constraints-and-adversarial-search/report.pdf) |
| MDP & reinforcement learning | Policy evaluation, policy iteration, and tabular Q-learning with discretized LunarLander observations | [Project](03-mdp-and-reinforcement-learning/) · [Report](03-mdp-and-reinforcement-learning/report.pdf) |
| Bayesian networks | Enumeration, variable elimination, rejection sampling, likelihood weighting, and Gibbs sampling | [Project](04-bayesian-networks/) · [Report](04-bayesian-networks/report.pdf) |

## Getting started

Use a separate virtual environment and install the requirements for the project you want to explore. Follow that project's README for its working directory and entry point. Notebook outputs and reports record course experiments; this repository does not claim independently reproduced benchmark results.

## Related projects

- [MyTorch from Scratch](https://github.com/kianasherafati/mytorch-from-scratch): NumPy-based differentiation and neural network foundations.
- [FER2013 Emotion Recognition](https://github.com/kianasherafati/fer2013-emotion-recognition-cnn): convolution and pooling work building on the MyTorch coursework.
- [Tetris with a Genetic Algorithm](https://github.com/kianasherafati/tetris-evolution-genetic-algorithm): evolutionary search with a visual game environment.
