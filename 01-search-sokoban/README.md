# Sokoban Search

A Pygame Sokoban project comparing depth-first search, breadth-first search, uniform-cost search, greedy search, and A* search. The code includes state transitions, path reconstruction, deadlock checks, and an interactive game interface.

## Run

From this directory:

```sh
python -m pip install -r requirements.txt
python main.py
```

Keep `pics/` beside `main.py`; the game resolves its image assets relative to the script.
